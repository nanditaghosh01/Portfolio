# Nandita Ghosh — Developer Portfolio ("Terracotta, Warm Linen & Forest Noir")

A modern, responsive, and ultra-polished personal developer portfolio website designed for **Nandita Ghosh**, Computer Science and Engineering student at Adamas University, aspiring software engineer, and developer specializing in AI/ML, web development, IoT, and robotics.

Styled with the curated **"Terracotta, Warm Linen & Forest Noir"** editorial palette, featuring circular portrait aesthetics, animated orbit rings, capsule tool cards, interactive project showcases, and direct PDF resume integration.

---

## Color Palette: Terracotta, Warm Linen & Forest Noir

| Color Code | Name | Role & Usage |
| :--- | :--- | :--- |
| **`#935542`** | Terracotta | Primary CTA buttons, action badges, interactive borders, and warm accent highlights |
| **`#C2755E`** | Terracotta Light | Dark mode primary accents, text highlights, glowing halo aura, and active tags |
| **`#F5EBE6`** | Warm Linen | Light mode soft blush canvas, dark mode typography, and circular portrait border |
| **`#1C1C19`** | Forest Noir | Dark mode base canvas, dark headers/footers, and espresso typography in light mode |
| **`#E6B959`** | Warm Gold | Accent star ratings, amber gradient highlights, and warm secondary glows |

---

## Key Features

1. **Circular Hero Portrait & Orbit Ring**
   - 380px circular frame with pure Linen border (`#FAF5F2`) and Terracotta shadow glow.
   - Ambient Terracotta & Warm Gold radial halo and rotating dashed orbital ring.
   - Single clean, unobstructed **"Software Engineer"** keyword badge centered below the portrait.

2. **"Exploring the Tools Behind My Code" Capsule Showcase**
   - Forest Noir & Espresso (`#2A2A25`) section with capsule cards for C++, Python, React.js, JavaScript, Arduino, Tailwind CSS, Git & GitHub, and VS Code.

3. **Interactive Projects Grid**
   - Filter tabs: All Projects | IoT & Robotics | Web Applications | Games & Logic.
   - 12 verified projects (LUMORA SHMS, VACUUM-X, Smart Helmet, ConceptFlow, IQ Tester, HabitTracker, CodeEscape, News Dashboard, Minesweeper, etc.).
   - Circular arrow action buttons in Terracotta (`#935542`) with crisp contrast arrows.

4. **Official PDF Resume Integration**
   - Direct download button for her official PDF resume (`Nandita_Ghosh_Resume.pdf`).
   - Interactive in-modal PDF viewer + standalone printable CV page at `assets/docs/Nandita_Ghosh_CV.html` styled with the Terracotta, Warm Linen & Forest Noir theme.

5. **Dual Theme System (Dark & Light Mode)**
   - Dark Mode: Forest Noir canvas (`#1C1C19`), Espresso cards (`#2A2A25`), Terracotta Light accents (`#C2755E`), Warm Linen typography (`#FAF5F2`).
   - Light Mode: Warm Linen canvas (`#F5EBE6`), Crisp White cards (`#FFFFFF`), Terracotta headings & buttons (`#935542`), Deep Espresso text (`#2E2A27`).

## How to Run Locally

```bash
npm start
# or
node server.js
```
The server automatically detects if port `5173` is in use and switches to the next available port (`5174`, `5175`, etc.).
